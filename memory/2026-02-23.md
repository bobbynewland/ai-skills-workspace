- **Kanban Enhancements**: Added Priority (High/Medium/Low) and Due Date fields to tasks. Overdue tasks flag in red.
- **Today Dashboard Improvements**:
  - "Top 3 Priorities" now syncs live from the Kanban board (sorted by Priority > Due Date). Tasks are clickable to instantly open their edit modal.

  - Added "View All Schedule" modal for a full list view of the next month's events.
- **Mobile Calendar UI**: Added a draggable, expandable bottom sheet to view, add, edit, and delete events seamlessly.
- **UX**: App now remembers the last active tab across page refreshes via `localStorage`.
